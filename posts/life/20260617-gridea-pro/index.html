强者归来：Gridea Pro —— 下一代桌面静态博客写作客户端

2026-06-17 · 阅需一刻

今天逛博客，偶然看到一个熟悉的名字：Gridea Pro。

记忆一下子被拉回 2020 年。那时刚接触博客，折腾了一圈 WordPress 觉得服务器太贵，GitHub Pages 又不会用，直到发现了 Gridea。
它在官网上是如此介绍自己的：

Gridea 是一个静态博客写作客户端，帮助你更容易地构建并管理博客或任何静态站点。

不用命令行，纯客户端写作，点一下发布就能推送。对一个连 Git 命令都没敲过几个的人来说，这简直就是量身定做的。

初遇与离开

刚开始用 Gridea 的时候，确实新鲜了一阵子。这个博客的第一篇文章——《Hello World！》，就是用它敲下的。

但新鲜感很快被现实击碎。最折磨人的是网络问题，GitHub 的访问状态堪称量子叠加态，时通时断。即使使用了虫洞穿越时空，同步文章时依然频繁转圈，十次有八次报错，成功发布反而成了小概率事件。每次点了发布按钮，都要做好失败的心理准备。

更让人无力的是，那时候 AI 还没普及，想调整主题样式，只能对着开源主题的代码干瞪眼。config.json 里的参数看不懂，模板文件改了就报错，自己改不动，也找不到人问。几次折腾下来，兴致消磨殆尽，终于忍痛告别。

后来又切换到 Vuepress，Typeecho，Halo 等，学着手动写配置、命令行生成、Git 推送。加上 AI 的辅助，最终又选择了现在的 Hugo，流程虽然繁琐了些，但至少稳定可控。Gridea 的事，也就渐渐淡忘了。

Gridea Pro

直到现在，原版 Gridea 停止维护大约四年后，Gridea Pro 出现了。

它不是简单的迭代，而是基于原版完全重写。技术栈从 Electron + Vue 换成了 Go + Wails + Vue 3，内存占用降到了 30-50 MB。原作者 EryouHao 创造了 Gridea 这个万星项目后忙于工作，由社区接力做出了 Pro 版本，延续了"让每个人都能零门槛拥有自己的博客"的初衷。

带着当年被网络问题折磨的记忆，我仔细看了看这个"老瓶新酒"，到底有什么变化。

先简单对比一下几个常见的静态博客方案：

Hugo 和 Hexo 是面向具有一定动手能力的开发者的工具，功能灵活、生态丰富，但需要一定的命令行经验。Gridea Pro 走的是另一条路：下载即用，所有操作都在 GUI 里完成。

三个在意的改变

功能很多，但最让我在意的有三个。恰好解决了当年让我离开的原因，现在来看，Gridea Pro 做出了一个满分的答案。

不再依赖系统 Git

当年同步文章转圈转到怀疑人生，本质上是底层 Git 同步的不稳定。Gridea Pro 用纯 Go 实现了 Git 引擎，不依赖系统安装的 Git。

少一个依赖，就少一个出错的环节。对于只想写文章的人来说，这个改变简单但有效。

主题配置可视化

以前对着 config.json 干瞪眼的场景还历历在目。Gridea Pro 支持主题参数可视化配置：主题开发者在配置文件中声明表单结构，用户直接在客户端界面里填写参数，不用再手动改配置文件。

目前内置了 9 款主题，涵盖多种风格。三种模板引擎（Jinja2/Pongo2、EJS、Go Templates）都支持。即使遇到想改但不会改的参数，至少不用对着代码发呆了。

AI 集成

Glidea Pro 实现了 MCP（Model Context Protocol） 协议，AI 助手可以直接操作博客。25+ 工具覆盖文章管理、闪念、标签、评论、主题配置等全流程，还内置了 5 个工作流。

当年要是能问 AI “这个主题参数怎么改”，可能也不会那么快放弃了。至少，现在卡壳的时候有个地方可以问——就像我写这篇文章时做的一样。

其他值得提的功能

  • Monaco Editor：VS Code 同款编辑器，语法高亮、智能补全、Vim/Emacs 键位
  • 闪念速记：灵感速记，支持 #标签 语法、图片附件、热力图统计
  • 多平台部署：GitHub Pages、Vercel、Netlify、Gitee、Coding、SFTP/FTP
  • 评论系统：Gitalk、Giscus、Disqus、Valine、Waline、Twikoo、Cusdis，勾选即用
  • SEO 自动生成：sitemap、RSS、社交分享 Meta 标签

写在最后

Gridea Pro 不是要替代 Hugo、Hexo 这些面向开发者的工具，它的定位很明确：降低博客写作的门槛。

如果你经历过命令行配置的折腾，或者被网络同步问题折磨过，又或者只是不想在写博客这件事上花太多时间折腾环境，Gridea Pro 值得一试。

当年那个让我忍痛告别的老朋友，换了一副更好的模样回来了。这次，也许可以多给它一点时间。
